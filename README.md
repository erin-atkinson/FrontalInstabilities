# CREATE Module: Modelling instability of a submesoscale front using Oceananigans
This is a module designed for the NSERC CREATE grant _Training for novel directions in quantitative climate science_. 

Begin by reading `notes/0-introduction.md` for an explanation and outline of the content of the module. Partially completed simulation, plotting and analysis scripts are in `src`. Exercises throughout the module instruct you to fill these out. Completed scripts are available in `src-complete` in case the coding exercises make no sense at all (my fault), and to check your own solutions.

CREATE requires proof of module completion via email. There is no set standard for this, I suggest creating a document including a write-up of completed exercises, inserted/modified code snippets and generated figures. Please then email this to Professor Nicolas Grisouard, the co-PI associated with this module (contact information is in link below).

Originally created in March 2026 by Erin Atkinson and [Nicolas Grisouard](https://sites.physics.utoronto.ca/nicolasgrisouard/group)

This is a working document, and future students are encouraged to update it, as part of their module contribution requirement, as the software develops.
